# Amazon Price Tracker

🌐 [English](Home) · [Dansk](Home-da) · **Bahasa Melayu**

Bot Python untuk Hari ke-47 kursus Udemy "100 Days of Code: The Complete Python Pro Bootcamp". Ia membaca halaman produk, mengambil harga dan menghantar e-mel apabila harga berada di bawah harga sasaran. Tugasan ini mempunyai empat langkah; setiap langkah ada halaman di sini yang menunjukkan apa yang dibina, tangkapan skrin dan **apa yang kita perolehi**.

| Langkah | Halaman | Apa yang kita perolehi |
| --- | --- | --- |
| 1 | [Ambil harga](Step-1-Scrape-the-Price-ms) | Membaca HTML dengan BeautifulSoup dan menukar `$99.99` kepada nombor perpuluhan |
| 2 | [Amaran e-mel](Step-2-Email-Alert-ms) | Menghantar e-mel dengan `smtplib` dan menyimpan rahsia dalam `.env` |
| 3 | [Header permintaan](Step-3-Request-Headers-ms) | Mengapa skrip perlu kelihatan seperti pelayar |
| 4 | [Halaman Amazon sebenar](Step-4-Live-Amazon-ms) | Apa yang berlaku di laman sebenar, dan cara gagal dengan jelas |

Jalankan: lihat [README](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/047-amazon-price-tracker#-setup) (persekitaran maya, `python -m pip install --upgrade pip`, `.env`).
