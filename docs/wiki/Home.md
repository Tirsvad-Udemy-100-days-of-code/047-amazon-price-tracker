# Amazon Price Tracker

🌐 **English** · [Dansk](Home-da) · [Bahasa Melayu](Home-ms)

A Python bot for Day 47 of Udemy's "100 Days of Code: The Complete Python Pro Bootcamp". It reads a product page, extracts the price and sends an e-mail when the price is below a target. The assignment has four lecture steps; each has a page here that shows what we built, a screenshot and **what we gained**.

| Step | Page | What we gained |
| --- | --- | --- |
| 1 | [Scrape the price](Step-1-Scrape-the-Price) | Reading HTML with BeautifulSoup and turning `$99.99` into a float |
| 2 | [E-mail alert](Step-2-Email-Alert) | Sending mail with `smtplib` and keeping secrets in `.env` |
| 3 | [Request headers](Step-3-Request-Headers) | Why a script should look like a browser |
| 4 | [Live Amazon page](Step-4-Live-Amazon) | What happens on a real site, and how to fail clearly |

Run it: see the [README](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/047-amazon-price-tracker#-setup) (virtual environment, `python -m pip install --upgrade pip`, `.env`). Code, plan and reviews: [repository](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/047-amazon-price-tracker).
